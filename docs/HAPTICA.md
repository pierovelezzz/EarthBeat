# Vibración opcional

> Revisión documental: **14/11/2026 20:29:05 (UTC-05:00)** · EarthBeat `V1`.
> El alcance se refiere al código y los recursos de esta rama. Las fechas de observaciones y los avisos de licencia conservan su significado original.

La preferencia vibe empieza desactivada. El componente comprueba la disponibilidad de la API y gestiona pulsos, límites y cancelación; una API disponible o una llamada aceptada no demuestra vibración física. El usuario debe poder detenerla. Las pruebas simuladas verifican intención y ciclo de vida, no el motor de un teléfono.
