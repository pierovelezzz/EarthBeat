# Prueba práctica con imágenes y lluvia

En ¿Cómo funciona? → Prueba práctica puedes comenzar con el logo de EarthRhythm o elegir una imagen local.

La interfaz permite PNG, JPG/JPEG, WebP y GIF. El límite de archivo es 8 MiB y el límite de imagen es 32 millones de píxeles. Una imagen animada se analiza como imagen fija. El encuadre de 560 × 320 conserva su proporción con transparencia exterior.

Los archivos se leen con las APIs del navegador; no se suben a un servicio. Las selecciones pendientes se identifican para que una carga anterior no sustituya a otra más reciente. Un error de formato, lectura o tamaño conserva el archivo previamente aceptado. Las URL locales se liberan al sustituirlas o cerrar el componente.

El mismo reproductor permite escuchar el análisis. Los controles de paleta representan patrones de color. La imagen propia se describe sin asignar una temperatura ni una ubicación geográfica.
