## Summary · English draft

TerraSonic is a bilingual educational prototype that turns patterns in stored Pacific ocean visualizations into synthesized music. Users choose dated NASA maps or try a local image and a Chiclayo rainfall example. A 28 by 16 grid connects image-derived levels to five musical characters. The interface provides written explanations, keyboard controls, readable-text options and reduced motion. Its illustrated introduction is distinct from the scientific maps. The application runs locally in the browser without an AI music service. It is not calibrated measurement, live monitoring or an early-warning system.
