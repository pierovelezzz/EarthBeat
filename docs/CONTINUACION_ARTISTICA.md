# Alcance artístico de V2

> Revisión documental: **14/11/2026 20:29:05 (UTC-05:00)** · EarthRhythm `V2`.
> El alcance se refiere al código y los recursos de esta rama. Las fechas de observaciones y los avisos de licencia conservan su significado original.

El build distribuye `pose-banda.webp`, `pose-banda-animada.webp`, `escenario.webp` y `miniatura-banda.webp` de cada músico. Los cinco `pose-banda-animada.webp` contienen siete fotogramas; esta rama no tiene `scripts/band-dance.js` ni carpetas `baile/`.

La rama no incluye los estudios 3D ni sus bibliotecas. No hay una tarea activa de reconstrucción Blender implícita por conservar este documento.

Las cinco ilustraciones fuente y los prompts siguen en `assets/avatares/`. El cambio de metadatos de una copia no equivale a redibujar ni a modificar sus píxeles. Las referencias culturales de personajes siguen en el catálogo y requieren revisión humana.

Las futuras modificaciones artísticas deben contrastarse con el recurso efectivo de esta rama y volver a comprobar movimiento reducido, carga y legibilidad. Este documento describe el alcance presente; no declara una aprobación visual pendiente como obtenida.
